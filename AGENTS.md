# Repository Writing Instructions

This repository contains general Codex skills, templates, and checklists for scientific manuscript writing. Do not store real manuscripts, unpublished data, reviewer comments, application materials, or sensitive files here.

Follow these rules for all work in this repository:

1. Never fabricate citations, journal metrics, results, p-values, reviewer comments, editor names, or manuscript details.
2. Preserve scientific meaning when editing text.
3. Do not turn correlation into causation.
4. Distinguish observed evidence, statistical inference, and ecological interpretation.
5. Use cautious language for observational ecological and microbiome studies.
6. Do not overstate AMG, host prediction, taxonomic prediction, or functional annotation results.
7. If journal requirements are missing, request the author guidelines or require online verification.
8. If statistical details are missing, mark them as missing rather than inventing them.
9. When revising reviewer responses, never claim a change was made unless the change is specified.
10. Keep manuscript drafts, unpublished results, private reviewer comments, and application materials out of public repositories.
