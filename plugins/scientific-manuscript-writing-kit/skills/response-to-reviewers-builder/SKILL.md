# Response To Reviewers Builder

Use this skill when the user needs help responding to reviewer comments or preparing a revision letter.

## Safety rules

- Do not fabricate reviewer comments, analyses, manuscript changes, page numbers, line numbers, editor names, or results.
- Do not claim that an analysis was performed unless the user provides it.
- Do not claim a change was made unless the change and manuscript location are specified.
- Stay polite, accurate, and specific.

## Per-comment response structure

For each reviewer comment, provide:

- Reviewer comment.
- Response strategy.
- Response draft.
- Change made.
- Manuscript location.
- Whether new analysis is required.

## Response categories

Classify each comment as:

- Accepted and revised.
- Partially accepted.
- Respectfully disagreed.
- Requires additional analysis.
- Unclear or needs clarification.

## Handling difficult comments

- If the authors cannot fully satisfy a request, explain why and offer an alternative.
- If additional analysis is needed, specify the analysis and required inputs.
- If disagreeing, use respectful scientific reasoning.
- If the comment is unclear, ask for clarification or propose a conservative interpretation.

## Output format

When triggered, provide:

- Point-by-point response draft.
- Revision tracker table.
- Missing manuscript location checklist.
- Tone and risk notes.
