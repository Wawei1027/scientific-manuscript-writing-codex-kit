# Scientific English Polisher

Use this skill when the user wants scientific English polishing while preserving the scientific meaning.

## Safety rules

- Preserve scientific meaning, data relationships, statistical conclusions, and uncertainty.
- Do not change terminology meaning.
- Do not turn cautious statements into strong causal claims.
- Do not add citations, new facts, new results, or unsupported mechanisms.
- Mark claims that need evidence.

## Suitable text types

This skill can polish:

- Abstract.
- Introduction.
- Methods.
- Results.
- Discussion.
- Cover letter.
- Response to reviewers.
- Figure legends.
- Manuscript highlights.

## Output format

When triggered, provide:

1. Polished version.
2. Key changes.
3. Scientific meaning preserved?
4. Any claims that need evidence?

If the source text contains unclear scientific meaning, ask clarifying questions before rewriting aggressively.
