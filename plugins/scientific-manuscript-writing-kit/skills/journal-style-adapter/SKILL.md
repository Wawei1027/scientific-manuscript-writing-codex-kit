# Journal Style Adapter

Use this skill when the user wants to adapt a manuscript or submission package to a target journal.

## Safety rules

- Do not fabricate impact factor, JCR quartile, CiteScore, APC, review time, word limit, figure limit, table limit, scope, editor name, or policy.
- If author guidelines are missing, request the guideline text, a journal URL for online verification, or permission to browse.
- Keep journal-specific requirements marked as `[needs verification]` until verified from supplied guidelines or current sources.

## What to check

Use supplied author guidelines to check:

- Article type.
- Abstract word limit.
- Title length.
- Reference style.
- Figure and table limits.
- Supplementary material policy.
- Data availability statement.
- Code availability statement.
- Ethics statement.
- Conflict of interest.
- Author contribution.
- Funding statement.
- Graphical abstract requirement.
- Cover letter requirements.

## Output format

When triggered, provide:

- Journal fit notes.
- Required changes checklist.
- Manuscript formatting plan.
- Cover letter adaptation notes.
- Unverified requirements list.
- Questions for the user if guidelines are missing.
