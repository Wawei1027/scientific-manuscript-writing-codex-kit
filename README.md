# Scientific Manuscript Writing Codex Kit

This repository is a personal Codex plugin marketplace for scientific manuscript writing, revision, submission preparation, cover letters, response to reviewers, Methods reproducibility checks, Results and Discussion logic, journal adaptation, and scientific English polishing.

It is designed for general writing workflows, templates, and checklists. It does not store real manuscripts, unpublished data, private application materials, reviewer comments, or other sensitive information.

## Plugin

- Marketplace: `.agents/plugins/marketplace.json`
- Plugin: `scientific-manuscript-writing-kit`
- Manifest: `plugins/scientific-manuscript-writing-kit/.codex-plugin/plugin.json`

## Skills

- `manuscript-structure-editor`: Review manuscript logic, novelty, section flow, and claim support.
- `microbiome-results-writer`: Turn microbiome, metagenomics, virome, and statistical outputs into cautious Results paragraphs.
- `discussion-logic-builder`: Build Discussion outlines and interpretations without overstating causality.
- `methods-reproducibility-auditor`: Audit Methods for missing versions, databases, parameters, thresholds, and statistical formulas.
- `journal-style-adapter`: Adapt manuscripts and submission materials to verified journal author guidelines.
- `cover-letter-writer`: Draft professional journal cover letters without exaggerating novelty or inventing journal details.
- `response-to-reviewers-builder`: Draft point-by-point reviewer responses and revision trackers.
- `scientific-english-polisher`: Polish scientific English while preserving meaning and uncertainty.

## Install

```bash
/Applications/Codex.app/Contents/Resources/codex plugin marketplace add Wawei1027/scientific-manuscript-writing-codex-kit --ref manuscript-writing-skills
```

## Usage Examples

```text
Use the manuscript-structure-editor skill to review my manuscript outline for logic, novelty, and section flow.

Use the microbiome-results-writer skill to turn my PERMANOVA and PCoA results into a cautious Results paragraph.

Use the discussion-logic-builder skill to build a Discussion outline without overstating causality.

Use the methods-reproducibility-auditor skill to audit my Methods section for missing software versions, databases, parameters, and statistical formulas.

Use the response-to-reviewers-builder skill to draft a point-by-point response to reviewers.
```

## Privacy

Keep real manuscript drafts, unpublished results, reviewer comments, application materials, private correspondence, raw data, and sensitive files out of this repository.
