# Smoke Test Prompts

Use these prompts after installing the plugin to confirm that the skills trigger correctly. Use only public, placeholder, or sanitized text.

## Manuscript structure

```text
Use the manuscript-structure-editor skill to review this manuscript outline for logic, novelty, section flow, and claim support: [paste a non-sensitive outline].
```

## Results writing

```text
Use the microbiome-results-writer skill to turn these sanitized PERMANOVA, alpha diversity, and PCoA summary results into a cautious Results paragraph: [paste placeholder results].
```

## Discussion logic

```text
Use the discussion-logic-builder skill to build a Discussion outline that separates observed evidence, statistical inference, ecological interpretation, limitations, and future work.
```

## Methods reproducibility

```text
Use the methods-reproducibility-auditor skill to audit this Methods section for missing software versions, database names, database dates, parameters, thresholds, and statistical formulas: [paste sanitized Methods text].
```

## Journal adaptation

```text
Use the journal-style-adapter skill to adapt this manuscript checklist to a target journal. Mark author-guideline details as requiring online verification unless I provide the guideline text.
```

## Cover letter

```text
Use the cover-letter-writer skill to draft a concise journal cover letter from this sanitized manuscript summary: [paste title, article type, main finding, and fit statement].
```

## Response to reviewers

```text
Use the response-to-reviewers-builder skill to draft a point-by-point response table from these sanitized reviewer comments and planned revisions: [paste comments and revision notes].
```

## Scientific English polishing

```text
Use the scientific-english-polisher skill to polish this paragraph for clarity and concision without changing the scientific meaning: [paste sanitized paragraph].
```
